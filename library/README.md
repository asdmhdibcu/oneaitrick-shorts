# 3D art library

Microsoft Fluent Emoji 3D (MIT licence), upscaled 4× to 1024×1024 with Real-ESRGAN x4plus. Copy what a short needs into its `assets/3d/`. To add art, put the entry in `tools/fetch_fluent.py`, fetch it, upscale it and commit the 1024 px PNG here.
