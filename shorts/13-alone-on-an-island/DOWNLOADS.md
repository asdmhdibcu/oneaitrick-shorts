# Short #13: download checklist for the creator

The workspace can't reach Pexels, Pixabay, Mixkit, Coverr, Wikimedia or arXiv, so these come from you. Save each file
with the name in the first column and attach them; I put them in `work/footage/` (git-ignored). I found these pages
through search but couldn't open them, so give each a quick look first: no watermark, no logos, no text, no faces up
close. Take the highest quality offered (4K if there, else 1080p). Pick one per row; the others are back-ups.

Pexels, Pixabay and Coverr clips are free for commercial use. **Skip Mixkit clips marked "Restricted" or "personal
use only".**
